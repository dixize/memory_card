# 🧠 Memory Card

Небольшая игра **Memory Card**, созданная на Python.

Цель игры — находить одинаковые пары карточек, запоминая их расположение. Проект сделан как простой учебный проект для практики Python и работы с игровой логикой.

## 🎮 Как играть

1. Запустите игру.
2. Перед вами появятся закрытые карточки.
3. Открывайте карточки по две.
4. Если карточки совпали — пара остаётся открытой.
5. Если карточки разные — они снова закрываются.
6. Продолжайте, пока не найдёте все пары.

## 🛠️ Технологии

* **Python 3**
* Python Standard Library

## 🚀 Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/dixize/memory_card.git
cd memory_card
```

Запустите игру:

```bash
python my_memory_card.py
```

Если команда `python` не работает в Windows, попробуйте:

```bash
py my_memory_card.py
```
